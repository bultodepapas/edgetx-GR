EdgeTX is open-source firmware for R/C transmitters. This workspace also contains GaugePro, a responsive Lua 5.3/LVGL telemetry widget under WIDGETS/GaugePro, plus a native-simulator visual validation kit under tools/gaugepro-visual-kit. Main repo areas: radio/ firmware and simulator, companion/ desktop app, WIDGETS/GaugePro widget, tools/gaugepro-visual-kit capture/report tooling, docs/ documentation. GaugePro mirrors the SD-card WIDGETS layout; main.lua is boot-light and lazy-loads app/module code.
